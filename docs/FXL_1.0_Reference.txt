OBJECT CREATION FORMS
---------------------

With import FXL.Objects:

1. Direct object creation:
rectangle(...)

2. Named object creation:
hinh_chu_nhat = rectangle(...)

Without import FXL.Objects:

3. Object type assigned through Objects:
rectangle = Objects(...)

4. Named object + object type assigned through Objects:
hinh_chu_nhat = rectangle = Objects(...)

Official forms:
with import Objects
rectangle(...)
hinh_chu_nhat = rectangle(...)

without import Objects
rectangle = Objects(...)
hinh_chu_nhat = rectangle = Objects(...)

`rectangle` is an Object Type when FXL.Objects is imported.
`Objects` is the object-creation form used when FXL.Objects is not imported.


IDENTIFIER RULES
----------------
- Identifier must be unique across the entire file.
- Duplicate identifier declaration is invalid.
- Error code: E_DUPLICATE_IDENTIFIER
- Object Type and identifier are distinct concepts.
- background is an identifier name, not an Object Type.
- rectangle is an Object Type.
- Rect is not an official FXL Object Type.
